# VideoChat Pro

## Cómo usarlo
1. Sube TODO el contenido de esta carpeta a tu repositorio de GitHub (incluida la carpeta `.github`).
2. En el repo: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
3. Espera unos 5 minutos. En la carpeta **apk** aparece `VideoChatPro.apk`.

## Dónde está cada cosa
- **La web**: `https://TU_USUARIO.github.io/NOMBRE_REPO/`
- **La APK**: carpeta `apk/VideoChatPro.apk` (también se descarga desde `https://TU_USUARIO.github.io/NOMBRE_REPO/apk/VideoChatPro.apk`). Instálala permitiendo "orígenes desconocidos".

## Cambiar los vídeos
Reemplaza `videos/v1.mp4 … v4.mp4` (mantén los nombres) y vuelve a subir. La APK se regenera sola.
